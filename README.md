# 3MF Translator 2 — بروفايلك المحلي، دون استيراد الفلمنت

هذه النسخة تنقل إعدادات المشروع مثل ارتفاعات الطبقات والحشوة والجدران والسرعات والأجسام، وتستبعد إعدادات الفلمنت القادمة من الملف.

البروفايل الافتراضي في OrcaSlicer هو **Creality K2 Plus 0.4 nozzle - wifi** الموجود أصلًا في مكتبة المستخدم. يبقى الاسم مطابقًا تمامًا، ولا ينشئ البرنامج بروفايل طابعة إضافيًا داخل المشروع. لا يعدّل ملف البروفايل المحفوظ أو إعدادات Wi-Fi، ولا يضمّن عنوان الطابعة أو مفاتيح اتصالها في 3MF.

## التشغيل

افتح `Start_Translator.vbs`، أو `Run_Translator.bat` لرؤية رسائل التشغيل. يستخدم المشغل Python 3.13 المثبت محليًا عند توفره. تحتاج Python مع PyQt6؛ حزمة PyQt6 متوفرة على الجهاز الذي اختُبر عليه التعديل. في جهاز آخر ثبّت المتطلبات من `requirements.txt`.

1. افتح مشروع 3MF ذا بروفايل JSON مدمج.
2. اترك السلايسر OrcaSlicer والفوهة 0.4 والبروفايل `Creality K2 Plus 0.4 nozzle - wifi` كما تظهر افتراضيًا، أو اختر بروفايلًا آخر موجودًا لديك.
3. احفظ أو حوّل وافتح في السلايسر.
4. اختر الفلمنت وألوانه وخصائصه بنفسك في السلايسر، ثم أعد التقطيع وراجع المعاينة قبل الطباعة.

عند اختيار Creality Print يعرض البرنامج بروفايلاته المتاحة، ولا يفترض أن بروفايل Wi-Fi المحفوظ في Orca موجود فيه أيضًا.

## ما الذي يستبعده؟

لا تُستورد بروفايلات الفلمنت المدمجة، ولا أسماؤها أو أنواعها أو ألوانها أو قطرها أو حرارتها أو نسب التدفق أو إعدادات التبريد والمعايرة. تُزال أيضًا خصائص المادة المضمّنة في إعدادات الأجسام والعملية ونتائج التقطيع القديمة. يكتب المشروع مراجع إلى بروفايلات مواد محلية أصلية فقط؛ لا يُنشئ بروفايلات فلمنت جديدة. يتجنب اختيار بروفايل خارجي مؤقت كان مفتوحًا من مشروع سابق بوصفه بروفايلًا محليًا.

تبقى أرقام الخيوط المخصصة للأجزاء وتبديلات الأدوات وارتفاعات أحداث الطبقات لأنها جزء من ترتيب الطباعة. حُذفت ألوان المصدر من أحداث الطبقات، وتبقى معاينة الصورة الأصلية للمجسم إن وجدت. اضبط المواد والفتحات المناسبة قبل التقطيع، خصوصًا للمشاريع متعددة الخيوط.

اسم بروفايل العملية وإعدادات جودة الطباعة لا يعاد تسميتها إلى HueForge بناءً على التخمين. كذلك لا يتغير قطر الفوهة تلقائيًا عند تحميل ملف دقيق الطبقات. التوسيط اختياري ومعطل افتراضيًا للحفاظ على المواضع.

## التحقق والحدود

نفذ `python -m unittest discover -s tests -v`. تغطي الاختبارات استبعاد المواد والبيانات المضمّنة، وحفظ الإعدادات والمواضع وأحداث الطبقات، والاسم الأصلي للبروفايل، وعدم تغيير المصدر وبروفايل Wi-Fi أو تسريب الاتصال.

لا يرسل البرنامج أمر طباعة أو يختبر اتصال Wi-Fi. الربط يكون باسم البروفايل الموجود في السلايسر؛ يلزم وجود ذلك البروفايل في الجهاز الذي يفتح الناتج. لم تعتمد طباعة فعلية أو مقارنة دقة مع البرنامج التجاري. دعم تنسيقات السلايسرات المختلفة ليس شاملًا؛ هذه النسخة تعتمد `Metadata/project_settings.config` بصيغة JSON.

ملف `profiles/slicer-options.json` يحدد مجموعات إعدادات الآلة والفلمنت والعملية المستخرجة من مصدر OrcaSlicer وCreality Print. `machines-by-slicer.json` يحتوي بروفايلات آلات احتياطية عند تخزين مكتبة السلايسر بصيغة حزمة. القيم المخصصة في بروفايل المستخدم المحلي لها الأولوية، مع استبعاد حقول الاتصال والمواد من هذه القيم.
